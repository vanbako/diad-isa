- About
I'm creating a diad (24 bit) 6-stage RISC microarchitecture core
The main goal is to keep the pipeline as simple as possible and to avoid stalls where possible
Toolchain is currently iverilog

- Details
Board: OrangeCrab or ULX3S
instructions, all memories, (GP) general purpose registers are diad (24 bit) in size
(SSP) shadow stack pointer, (LR) link register, (PC) program counter are tetrad (48 bit) in size
memories are 24 bit addressable (not byte-addressable!)
integer & floating points math is not needed yet. They are for future extension
no branch prediction (keep spectres away), no out-of-order nor speculative execution (no meltdown), no interrupts, no exceptions, no cache, no TLB, no MMU
Use handshake signals between stages to allow stages to indicate when they can accept new data.
No multi-cycle instructions
Each stage has its own local hazard or control logic that communicates with adjacent stages.
Use the built-in synchronous Block RAM (BRAM) for both instruction and data memories (will be caches later), single-ported. Make sure to use a one-clock delay (fetch & mem stages)
Memory initialisation is with a bootloader at runtime (now as initialized with a memory file for testing)

- Instruction format
24 bit (diad) total, only those needed for the instruction are coded, the rest is marked as RESERVED and should be all zeros (not checked yet)
CC jump/branch condition code (0 = RA, 1 = EQ, 2 = NE, 3 = LT, 4 = GT, 5 = LE, 6 = GE, 7 = BT, 8 = AT, 9 = BE, A = AE)

- Instruction suffixes
ur: unsigned register operation
ui: unsigned immediate value (upper from uimm and lower from immxx)
sr: signed register operation
si: signed immediate operation (sign extended immxx)
so: signed immediate operation (sign extended immxx offset)

In the assembly language, first operand is source, second operand is target.

Move instructions set/clear Z flag (except for address instructions)
Address instructions (including LD/ST) do not touch flags, except for compare and test

All 48 bit memory operations are little endian (2x 24 bit)

For conditional instruction mnemonic (MCCxx, JCCxx, BCCxx), the CC is replaced by the condition code. (BRA = branch always, MEQ = move if equal, JAT = jump if above, etc.)

- Pipeline Stages
1. IA/IF: Instruction Address & Fetch
2. ID:    Instruction Decode
3. XT:    Translate
4. EX:    Execute
5. MA/MO: Memory Address & Operation
6. WB:    Register Write Back

- Data registers
0-15 DRx : data

- Address registers
0-3 ARx : address

- special registers
LR  : link register
ST  : special temporary
SSP : shadow stack pointer
PC  : program counter

- flags
FL  :
	0  Z zero
	1  N negative
	2  C carry
	3  V overflow

- memories
instruction:
	4096 diads (24 bits) in size, 24 bit address space
	read-only during pipeline operation (BRAM in Artix-7)
data:
	4096 diads (24 bits) in size, 24 bit address space
	read-write (BRAM in Artix-7)
